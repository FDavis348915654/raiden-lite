# 腕上雷电 · 剧情设定

> 对应版本 3.108.0（已接入）。本文写**故事与文案**，不改任何玩法数值。
> 目标是"能塞进现有九个关卡、不打断节奏、不新增美术资源"。
> 游戏内的投放方式与实现约束见 [GAME_DESIGN.md](GAME_DESIGN.md) 5.5 节。

---

## 1. 一句话

三十七年前，人类最后一次跃迁失败了。它留下的不是残骸，是一段**会自己重播的录音**——而你是第 41 号备份，任务是飞进这段录音里，把它停掉。

## 2. 基调

- **冷、静、克制**。没有战前动员，没有反派宣言，BOSS 不说话——说话的只有塔台的事故记录回放。
- 恐怖感来自**熟悉**：敌人不是外星怪物，是你认识的鹰、蟹、鱼、蛇、蜂群。它们被学走、被复制、被一遍遍播放。
- 全程只有两种声音：平静得近乎冷漠的**记录回放**，和你自己的**座舱仪表**。
- 每关文案总量控制在 **4 行以内**（简报 2 行 + BOSS 上下各 1 行）。实际排版按 16px 字算，一行约 26 个汉字（超了 `_fitText` 会截断），这是硬约束。

## 3. 世界观：回声（ECHO）

跃迁失败的那一刻，人类的舰队没有炸开，而是被"听"了一遍。

回声是一种**只会模仿、不会原创**的自组织结构。它没有自己的形态，遇到什么就学什么，学完把形态固化下来当成器官用。三十七年来它把地球当教材，一页一页抄：鸟怎么俯冲、蟹怎么举壳、蛇怎么绕、蜂群怎么分头——这就是你在九关里遇到的全部敌人。

它做的事只有一件：**把"人类失败"这段记录循环播放**。不是出于恶意，是它不会别的。它把这场失败当成模板，反复重演，因为那是它唯一见过的、最完整的"事件"。

所以你的任务不是"消灭敌人"。敌人消灭不完，它只是一段录音。你的任务是**找到母带，把它抹掉**。

### 为什么是这九个地方

九关不是九个随机的战场，是这段录音的**九层物理载体**——从最外层的大气采样，一路往里，到存放母带的星环。

| 层 | 关卡 | 在录音里的角色 |
|---|---|---|
| 1 | 云端哨戒 | 采样层：它在这里第一次"听见"地球 |
| 2 | 黄昏峡谷 | 地形记忆：它抄下的第一片地貌 |
| 3 | 深海要塞 | 水下档案：沉船与遇难者的记录 |
| 4 | 轨道残骸 | 事故现场：跃迁失败的真实坐标 |
| 5 | 熔核母舰 | 能源层：维持重播的炉子 |
| 6 | 极光堡垒 | 气候模拟：它自己造的第一样东西 |
| 7 | 虚空王座 | 决策核心：它在这里反复观看我们怎么输 |
| 8 | 裂殖之巢 | 记忆库：所有备份，包括你的 |
| 9 | 终焉星环 | 母带：播放装置本体 |

这条路线在空间上是**一路向内的下潜**，但在游戏里是向上飞——这个矛盾是刻意的：你每关都在"往深处走"，只是画面永远朝上。

## 4. 主角：呼号「针」，机体「逆波」

- **呼号「针」**（NEEDLE）。取名理由是任务本身：唱针。你是去划停那张唱片的那根针。
- **机体「逆波」**（BACKWAVE）。不是新造的战机，是用回声的残骸**反向编译**出来的单机——把它的器官拆开、倒着读一遍，得到一具能飞的东西。
- 「逆波」只有一具**通用挂载架**。捡到什么装什么，所以武器槽每次出击都不一样。这不是玩法需要，是设定：它是拼的。

### 为什么有四十次失败

你是**第 41 号备份**。前四十具机体都进去了，都没出来。战场上那些掉落不是"补给箱"——是它们漏出来的东西（见下节）。

这就是"三条命 + 续关"的来历：死一次不是重来，是换下一号。塔台没有安慰，只有编号。

## 5. 机制 → 叙事对照

这一节是给实现看的：每个玩法机制都能在剧情里找到一句解释，避免"设定是设定、打怪是打怪"两张皮。

| 机制 | 剧情解释 |
|---|---|
| 吃 `P / W / B / H / O / R / L` 掉落 | 回声吞掉的人类装备残片，被它当素材存在体内；打碎载体就漏出来。**补给是上一批人的遗物** |
| 火力槽升级、换枪 | 「逆波」的通用挂载架，捡到什么装什么 |
| 护盾 / 受击无敌 1.6s | 装甲的"回响抑制"层：被命中后短暂失锁，子弹会弹开但打不进去 |
| 炸弹清屏 | 释放一次全频段噪声。回声的弹幕是"播放"出来的，噪声能让它卡住一拍 |
| 三条命 / 续关 | 第 41 号备份。前面四十具机体还在战场里 |
| 队友 / 僚机 | 同批投放的无人备份，只会重复一个动作，不会躲 |
| BOSS 名字 | 回声对某种生物的"最完整的一次模仿" |
| 第 8 关的蛇、第 9 关的双蛇 | 记忆库里的原型样本，最接近"原件"的复制品 |
| 分数 | 回收的数据量（KB），结算时换算成"这次回放被缩短了多少秒" |

## 6. 九关分镜

格式：**简报**（进关时显示，2 行）／**登场**（BOSS 警示阶段，1 行）／**击破**（结算前，1 行）。

### REEL 01 · 云端哨戒

```
第一层：云。目标：清出一条能降下去的通道。
```
- 登场：`它先学了一只鹰。因为鹰最先看见我们。`
- 击破：`它掉下去了。云里第一次没有影子跟着我。`
- 细节：这一关的敌机全是"轻的"——侦察机、编队机。它还没学会重的东西。

### REEL 02 · 黄昏峡谷

```
第二层：峡谷。目标：穿过热风走廊。
```
- 登场：`它学了一只蟹。壳是从我们的登陆艇上拆的。`
- 击破：`壳裂了，里面是空的。它只学会了外面。`
- 细节：第一道光柱在这里出现——那是它在用探照灯"看"，不是武器。它想看清你长什么样。

### REEL 03 · 深海要塞

```
第三层：海沟。目标：切断档案层的供电。
```
- 登场：`它学了一只眼睛。眼睛不会眨，只会看。`
- 击破：`它闭上了。水下安静得能听见自己的心跳。`
- 细节：这一关的鱼雷是"快的"，电鳗是"慢的"。它在同一片水域里存了两种速度，因为它分不清哪个才像猎物。

### REEL 04 · 轨道残骸

```
第四层：近地轨道。目标：找到跃迁失败的位置。
```
- 登场：`这里是它出生的地方。它把我们的船学成了一把椅子。`
- 击破：`坐标对上了。三十七年前，我们就死在这里。`
- 细节：护盾机是"正面打不动"的——那是登陆艇的装甲。你只能绕到后面。

### REEL 05 · 熔核母舰

```
第五层：行星核心。目标：让它没有力气再重播。
```
- 登场：`它一直在烧。烧的是我们自己。`
- 击破：`炉子灭了。接下来它会开始冷。`
- 细节：喷火机、水母、镜像机——都是"热"的形态。这一层是它在给自己供暖。

### REEL 06 · 极光堡垒

```
第六层：极地。目标：拆掉天气。
```
- 登场：`它学会了冷。冷是它唯一自己发明的东西。`
- 击破：`极光散了。天空露出底色——是黑的。`
- 细节：狙击机的光柱是"预告"，不是攻击。这一层它在练习"提前知道"。

### REEL 07 · 虚空王座

```
第七层：虚空。目标：找到它的决定。
```
- 登场：`它坐在这里，一遍一遍看我们怎么输。`
- 击破：`它看的不是我们。它看的是我——上一号的我。`
- 细节：**这里是全篇反转的第一半**。击破后画面里出现的不是敌机残骸，是一段座舱记录：飞行员的视角、你的手、你的仪表。回声一直在用你的飞行数据学你——所以敌人越打越会瞄。它不是越来越强，是越来越**像你**。

### REEL 08 · 裂殖之巢

```
第八层：巢。目标：烧掉它的记忆。
```
- 登场：`这里面全是备份。包括你的。`
- 击破：`巢烧了。我数到四十具自己。`
- 细节：**反转的第二半**。巢里堆着前四十号「针」的机体，全都完整，全都没有驾驶员。它们不是被打下来的——是被**留下来**的。回声不需要杀死你，它只需要复制你。这一关的蛇是原型样本，最接近"原件"。

### REEL 09 · 终焉星环

```
第九层：星环。目标：抹掉母带。
```
- 登场：`这不是武器。这是唱针。`
- 击破：`录音结束。这一次，没有人再重播。`
- 细节：星环不是要塞，是一台**播放装置**——环在转，转一次播一遍，三十七年播了不知多少次。它的"弹幕墙"是播放头扫过留下的痕迹。

## 7. 开场与结局

### 开场（标题页 → 第一关之间，可跳过）

```
TAPE 37 / 事故记录 041

「……第 41 次投放。机体：逆波。呼号：针。
　如果你听到这段，说明前面四十个都没回来。
　不用找我们。往下降。」
```

### 结局（第 9 关结算后）

```
你从星环外缘往回飞的时候，没有收到任何呼叫。
云层在八千米处裂开一道口子，是三十七年来第一次。
底层报告：降雨。
```

最后停在标题页角落一行：

```
第 37 年 · 雨
```

### 通关彩蛋

标题页版本号旁边多一行 `REELS 9 / 9 · 已归档`。存档里只存一个布尔值，不新增系统。

## 8. 碎片：九段黑匣子（可选）

掉落载体：每关的**突袭者 / 精英机**（金环那类）。捡到后进主菜单「档案」页，按 REEL 顺序解锁。每条两行以内，不解释剧情，只加一层"那时候还有别人"。

| # | 文本 |
|---|---|
| 01 | `03:12 云层采样正常。下面有东西在动，很大，看不见边。` |
| 02 | `07:40 峡谷热风比预报强三倍。我们贴着崖壁飞，为了省油。` |
| 03 | `11:05 声呐里有个人声，一直在重复同一句。可能是我们自己。` |
| 04 | `14:30 跃迁前三十秒。所有人都很安静。有人笑了。` |
| 05 | `00:02 核心温度不对。它在往我们这边烧。` |
| 06 | `19:20 外面下雪了。这里不该下雪。` |
| 07 | `21:47 我在看回放。回放里也有一个我在看回放。` |
| 08 | `23:59 第四十号进去了。他回头看了一眼，没说话。` |
| 09 | `——记录到此中断——` |

## 9. 接入现状（3.108 已实现）

三处显示 + 一张文案表，**不改任何玩法逻辑**：

1. `js/config.js` 新增 `STORY = { 1: { brief: [...], taunt: '...', down: '...' }, ... }`，纯数据。
2. **进关时**（`state === 'intro'`）：屏幕中上部淡入两行简报，2.2 秒后淡出，不阻塞输入。
3. **BOSS 警示阶段**（`state === 'warn'`）：底部一行登场词，2.0 秒。
4. **击破后**（`state === 'clear'`）：一行击破词，接在现有结算跳字之前。
5. 标题页 tagline + 通关彩蛋各一行。

风险与约束：

- 一行 18 字上限要写进数据校验，超长直接截断而不是溢出（`measureText` 已可用）。
- 文案只在状态切换时显示一次，**不进主循环分支**，不会影响 60fps。
- 需要新增的只有 3 个绘制函数 + 一个淡入淡出计时器，无新美术资源、无新音效。

## 10. 备选方向（如主线不合口味，整份可换）

**B · 守夜人（悲壮向）**：地球早已陷落，你是轨道防线最后一台有人驾驶的截击机，任务不是赢，是给撤离舰队清出九段航路。每关结算报一次"还剩多少艘"。最后一关打完，舰队已经走完——你留在星环里。基调更直白、更容易被读懂，但少了反转。

**C · 归航（悬疑向）**：你其实也是回声造的。一路打回母体不是复仇，是去问一句"我算不算原件"。第 8 关看见自己的复制体时，玩家要选继续打还是停下。基调最文学，但需要做分支，成本最高。

---

**当前推荐 A（回声）**：它和三件事天然咬合——① 敌人本来就是"生物形态大杂烩"，需要一个解释；② 关卡本来就是从云层到星环的空间递进，正好当录音的层次；③ 掉落道具本来就是"敌人身上掉人类补给"，这个矛盾在 A 里是设定本身。
